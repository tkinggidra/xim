# XIM

A DIY mouse-and-keyboard to controller adapter for PC, built on the RP2040.

## Repository layout
| Folder | Contents |
|---|---|
| `firmware/` | RP2040 firmware (PlatformIO) |
| `hardware/` | KiCad PCB project |
| `housing/` | Case CAD |
| `app/` | Optional config app |
| `docs/` | Design notes and guides |
